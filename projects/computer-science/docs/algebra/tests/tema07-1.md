## Soluciones explicadas: aprende pregunta por pregunta

<details class="solution">
<summary>1. Respuesta correcta: B — Definición de conjunto de Cantor</summary>

Según Georg Cantor, un **conjunto** es *"una colección bien definida de objetos bien distinguidos de nuestra percepción o pensamiento en un todo"*.
- **Sin orden:** El orden de los elementos no altera el conjunto. $\{1, 2, 3\} = \{3, 2, 1\}$.
- **Sin duplicados:** Los elementos repetidos no aportan elementos adicionales. $\{a, a, b\} = \{a, b\}$.
- **Finitos o infinitos:** Puede contener un número limitado o ilimitado de elementos.
</details>

<details class="solution">
<summary>2. Respuesta correcta: D — Conjuntos finitos e infinitos</summary>

Un conjunto es **finito** si su cardinalidad (número de elementos) es un número natural $n \in \mathbb{N}$.
- El conjunto de los días de la semana contiene exactamente 7 elementos: $\{\text{Lunes}, \text{Martes}, \dots, \text{Domingo}\}$.
- Los conjuntos numéricos $\mathbb{N}$ (naturales), $\mathbb{Z}$ (enteros) y $\mathbb{R}$ (reales) son conjuntos **infinitos** (denumerables o no denumerables).
</details>

<details class="solution">
<summary>3. Respuesta correcta: B — Producto cartesiano A × B</summary>

El **producto cartesiano** entre los conjuntos $A$ y $B$ (denotado $A \times B$) es el conjunto de todos los **pares ordenados**:
\[
A \times B = \{(a, b) \mid a \in A \land b \in B\}
\]
- El orden del par es estricto: la primera componente proviene del primer conjunto $A$ y la segunda componente del conjunto $B$.
- Si el cardinal de $A$ es $|A| = m$ y el de $B$ es $|B| = n$, el cardinal de $A \times B$ es $|A \times B| = m \cdot n$.
</details>

<details class="solution">
<summary>4. Respuesta correcta: C — Representación con diagramas de Venn</summary>

Los **diagramas de Venn** son ilustraciones gráficas utilizadas en la teoría de conjuntos para visualizar relaciones lógicas:
- El conjunto universo $U$ se representa mediante un rectángulo delimitador.
- Los conjuntos individuales se dibujan como regiones cerradas (círculos o elipses).
- Permite identificar fácilmente las operaciones de unión, intersección, diferencia y complemento.
</details>

<details class="solution">
<summary>5. Respuesta correcta: B — Intersección de conjuntos A ∩ B</summary>

La **intersección** $A \cap B$ es el conjunto formado exclusivamente por aquellos elementos compartidos por todos los conjuntos involucrados:
\[
A \cap B = \{x \mid x \in A \land x \in B\}
\]
En un diagrama de Venn, representa la zona central superpuesta donde se solapan los círculos de los conjuntos.
</details>

<details class="solution">
<summary>6. Respuesta correcta: B — Subconjuntos e inclusión A ⊆ B</summary>

$A$ es un **subconjunto** de $B$ ($A \subseteq B$) si todo elemento perteneciente a $A$ es también un elemento de $B$:
\[
A \subseteq B \iff (\forall x \in A \implies x \in B)
\]
- Si $A \subseteq B$ pero existe algún elemento en $B$ que no está en $A$, se dice que $A$ es un **subconjunto propio** ($A \subset B$).
- Todo conjunto es subconjunto de sí mismo ($A \subseteq A$) y el conjunto vacío es subconjunto de cualquier conjunto ($\emptyset \subseteq A$).
</details>

<details class="solution">
<summary>7. Respuesta correcta: B — Conjunto de las partes P(A)</summary>

El **conjunto de las partes** (o conjunto potencia) $\mathcal{P}(A)$ o $2^A$ es el conjunto formado por **todos los subconjuntos posibles** de $A$:
\[
\mathcal{P}(A) = \{X \mid X \subseteq A\}
\]
*Ejemplo:* Si $A = \{1, 2\}$, entonces $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$.
Nota: Siempre incluye al conjunto vacío $\emptyset$ y al propio conjunto $A$.
</details>

<details class="solution">
<summary>8. Respuesta correcta: D — Cardinalidad del conjunto potencia 2ⁿ</summary>

Si un conjunto finito $A$ tiene $|A| = n$ elementos, la cantidad de elementos en su conjunto de las partes es:
\[
|\mathcal{P}(A)| = 2^n
\]
**Explicación combinatoria:** Para construir cualquier subconjunto de $A$, para cada uno de los $n$ elementos tenemos exactamente 2 decisiones independientes: incluirlo o no incluirlo. Multiplicando 2 por sí mismo $n$ veces obtenemos $2^n$.
</details>

<details class="solution">
<summary>9. Respuesta correcta: D — Unión de conjuntos A ∪ B</summary>

La **unión** $A \cup B$ reúne todos los elementos que forman parte de $A$, de $B$ o de ambos:
\[
A \cup B = \{x \mid x \in A \lor x \in B\}
\]
En lógica y teoría de conjuntos, el operador "o" ($\lor$) es inclusivo.
</details>

<details class="solution">
<summary>10. Respuesta correcta: B — Complemento Aᶜ</summary>

El **complemento** de un conjunto $A$ respecto a un universo $U$ (denotado $A^c$, $\bar{A}$ o $U \setminus A$) comprende los elementos del universo que no pertenecen a $A$:
\[
A^c = \{x \in U \mid x \notin A\}
\]
Propiedades asociadas: $A \cup A^c = U$ y $A \cap A^c = \emptyset$.
</details>

<details class="solution">
<summary>11. Respuesta correcta: B — Definición de función</summary>

Una **función** $f$ de un conjunto $A$ (dominio) a un conjunto $B$ (codominio), denotada $f: A \to B$, es una relación especial que asigna a **cada** elemento $x \in A$ **un único** elemento $y \in B$.
- Todo elemento del dominio debe tener asignada una salida.
- Ningún elemento del dominio puede tener asignadas dos o más salidas diferentes.
</details>

<details class="solution">
<summary>12. Respuesta correcta: C — Función inyectiva (uno a uno)</summary>

Una función $f: A \to B$ es **inyectiva** (o uno a uno) si elementos distintos del dominio se transforman en elementos distintos del codominio:
\[
f(a) = f(b) \implies a = b \quad \text{o equivalentemente} \quad a \neq b \implies f(a) \neq f(b)
\]
Geométricamente, significa que cada elemento del codominio $B$ recibe como máximo una flecha o preimagen.
</details>

<details class="solution">
<summary>13. Respuesta correcta: B — Dominio vs Codominio vs Imagen</summary>

En una función $f: A \to B$:
- **Dominio ($A$):** Conjunto de elementos de entrada sobre los que la función está totalmente definida.
- **Codominio ($B$):** Conjunto global de llegada donde están declaradas las posibles salidas.
- **Imagen o Recorrido ($\text{Im}(f)$):** Subconjunto real del codominio formado por los elementos efectivamente alcanzados: $\text{Im}(f) = \{f(x) \mid x \in A\} \subseteq B$.
</details>

<details class="solution">
<summary>14. Respuesta correcta: A — Función biyectiva</summary>

Una función $f: A \to B$ es **biyectiva** si cumple simultáneamente dos condiciones:
1. Es **inyectiva** (no repite imágenes).
2. Es **suprayectiva** ($\text{Im}(f) = B$, todo el codominio es alcanzado).

**Propiedad fundamental:** Una función admite inversa $f^{-1}: B \to A$ si y solo si es biyectiva.
</details>

<details class="solution">
<summary>15. Respuesta correcta: B — Composición de funciones</summary>

Dadas dos funciones $f: A \to B$ y $g: B \to C$, la **composición** $g \circ f: A \to C$ consiste en evaluar la función $g$ sobre el resultado producido por $f$:
\[
(g \circ f)(x) = g(f(x))
\]
**Orden de evaluación:** Se aplica primero la función más cercana a la variable (en este caso $f$), y el valor obtenido se procesa posteriormente mediante $g$.
</details>

## Chuleta final: lo imprescindible para aprobar

### 1. Conceptos y operaciones de conjuntos

- **Conjunto:** Colección desordenada de elementos bien definidos.
- **Producto Cartesiano:** $A \times B = \{(a, b) \mid a \in A, b \in B\}$.
- **Unión ($A \cup B$):** $x \in A$ o $x \in B$.
- **Intersección ($A \cap B$):** $x \in A$ y $x \in B$.
- **Complemento ($A^c$):** Elementos del universo $U$ que no están en $A$.
- **Conjunto de las Partes ($\mathcal{P}(A)$):** Colección de todos los subconjuntos. Si $|A| = n \implies |\mathcal{P}(A)| = 2^n$.

### 2. Clasificación de funciones f: A → B

- **Función:** Cada $x \in A$ se relaciona con un **único** $y \in B$.
- **Inyectiva (Uno a Uno):** $f(a) = f(b) \implies a = b$. (Ninguna imagen se repite).
- **Suprayectiva (Sobre):** La Imagen es igual al Codominio ($\text{Im}(f) = B$). (No quedan elementos sueltos en $B$).
- **Biyectiva:** Inyectiva y Suprayectiva a la vez. Admite **función inversa** $f^{-1}$.

### 3. Composición de funciones

- **Fórmula:** $(g \circ f)(x) = g(f(x))$.
- **Evaluación:** Se evalúa de derecha a izquierda (primero $f$, luego $g$).

<script>
document.addEventListener("DOMContentLoaded", function () {
  const form = document.getElementById("quiz-form");
  if (!form || form.dataset.initialized === "true") return;
  form.dataset.initialized = "true";

  const questions = Array.from(document.querySelectorAll("#quiz-form .quiz-question"));
  const count = document.getElementById("quiz-count");
  const progressText = document.getElementById("quiz-progress-text");
  const result = document.getElementById("quiz-result");
  const scoreText = document.getElementById("quiz-score");
  const message = document.getElementById("quiz-message");
  const summary = document.getElementById("quiz-summary");
  const reset = document.getElementById("quiz-reset");

  function updateProgress() {
    const answered = questions.filter(q => {
      const input = q.querySelector("input");
      return form.querySelector('input[name="' + input.name + '"]:checked');
    }).length;
    count.textContent = answered + " de " + questions.length + " respondidas";
    progressText.textContent = answered === questions.length
      ? "¡Ya has respondido todas!"
      : "Te faltan " + (questions.length - answered) + " por responder.";
  }

  form.addEventListener("change", updateProgress);

  form.addEventListener("submit", function (event) {
    event.preventDefault();
    let correct = 0;
    let unanswered = 0;

    questions.forEach(function (question, index) {
      const number = index + 1;
      const selected = form.querySelector('input[name="q' + number + '"]:checked');
      const answer = question.dataset.answer;
      const shortExp = question.dataset.shortExp || "";
      const statusEl = question.querySelector(".feedback-status");
      const expEl = question.querySelector(".feedback-exp");
      const labels = question.querySelectorAll("label");

      question.classList.remove("is-correct", "is-wrong");
      labels.forEach(label => { label.style.fontWeight = "normal"; });

      if (!selected) {
        unanswered++;
        question.classList.add("is-wrong");
        statusEl.textContent = "✗ Sin responder. Respuesta correcta: " + answer.toUpperCase();
      } else if (selected.value === answer) {
        correct++;
        question.classList.add("is-correct");
        statusEl.textContent = "✓ ¡Correcto!";
      } else {
        question.classList.add("is-wrong");
        statusEl.textContent = "✗ Incorrecto. Respuesta correcta: " + answer.toUpperCase();
      }

      expEl.textContent = shortExp;

      const correctLabel = Array.from(labels).find(label =>
        label.querySelector("input").value === answer
      );
      if (correctLabel) correctLabel.style.fontWeight = "700";
    });

    const percent = Math.round(correct / questions.length * 100);
    scoreText.textContent = correct + " de " + questions.length + " correctas (" + percent + "%).";
    message.textContent = percent >= 90 ? "¡Excelente! Dominas muy bien el tema." :
      percent >= 70 ? "¡Buen trabajo! Repasa los fallos para afianzar lo aprendido." :
      percent >= 50 ? "Vas por buen camino. Lee las explicaciones cortas y detalladas para afianzar." :
      "Te conviene repasar las explicaciones detalladas con calma y repetir el test.";
    summary.textContent = unanswered
      ? "Has dejado " + unanswered + " pregunta(s) sin responder."
      : "Has respondido todas las preguntas.";

    result.hidden = false;
    result.scrollIntoView({ behavior: "smooth", block: "nearest" });

    if (window.MathJax && MathJax.typesetPromise) {
      MathJax.typesetPromise();
    }
  });

  reset.addEventListener("click", function () {
    form.reset();
    questions.forEach(function (question) {
      question.classList.remove("is-correct", "is-wrong");
      question.querySelectorAll("label").forEach(label => {
        label.style.fontWeight = "normal";
      });
      question.querySelector(".feedback-status").textContent = "";
      question.querySelector(".feedback-exp").textContent = "";
    });
    result.hidden = true;
    updateProgress();
    form.scrollIntoView({ behavior: "smooth", block: "start" });
  });

  updateProgress();
});
</script>
