## Soluciones explicadas: aprende pregunta por pregunta

<details class="solution">
<summary>1. Respuesta correcta: B — Definición de Producto Cartesiano</summary>

El **producto cartesiano** entre dos conjuntos $A$ y $B$ (escrito $A \times B$) es el conjunto constituido por todos los pares ordenados posibles tomando el primer elemento de $A$ y el segundo de $B$:
\[
A \times B = \{(a, b) \mid a \in A \land b \in B\}
\]
- Si $A$ tiene $m$ elementos y $B$ tiene $n$ elementos, la cantidad de elementos de $A \times B$ es $m \cdot n$.
- Es una estructura ordenada: $(a, b) \neq (b, a)$ salvo si $a = b$.
</details>

<details class="solution">
<summary>2. Respuesta correcta: C — Dominio de una relación</summary>

Dada una relación binaria $R \subseteq A \times B$:
- **Dominio ($\text{Dom}(R)$):** Es el subconjunto de $A$ formado por todos los elementos que aparecen como **primera componente** en algún par ordenado de $R$:
\[
\text{Dom}(R) = \{a \in A \mid \exists b \in B, (a, b) \in R\}
\]
- **Imagen / Rango ($\text{Im}(R)$):** Es el subconjunto de $B$ formado por todos los elementos que aparecen como **segunda componente**:
\[
\text{Im}(R) = \{b \in B \mid \exists a \in A, (a, b) \in R\}
\]
</details>

<details class="solution">
<summary>3. Respuesta correcta: B — Matriz Booleana</summary>

Una **matriz booleana** (o matriz binaria/cero-uno) es una matriz rectangular de $m \times n$ cuyas entradas sólo toman valores del álgebra de Boole:
\[
M_{ij} \in \{0, 1\}
\]
Se utiliza computacionalmente para representar grafos dirigidos y relaciones binarias finitas, donde $1$ codifica la presencia de una relación/arista y $0$ su ausencia.
</details>

<details class="solution">
<summary>4. Respuesta correcta: D — Producto Booleano de matrices</summary>

El **producto booleano** de dos matrices booleanas $A$ ($m \times k$) y $B$ ($k \times n$), denotado $A \odot B$, genera una matriz $C$ ($m \times n$) mediante la fórmula:
\[
c_{ij} = (a_{i1} \land b_{1j}) \lor (a_{i2} \land b_{2j}) \lor \dots \lor (a_{ik} \land b_{kj}) = \bigvee_{t=1}^k (a_{it} \land b_{tj})
\]
Opera como la multiplicación matricial estándar, reemplazando la suma $+$ por el **OR lógico** ($\lor$) y la multiplicación $\cdot$ por el **AND lógico** ($\land$).
</details>

<details class="solution">
<summary>5. Respuesta correcta: C — Representación matricial de relaciones</summary>

Si $R$ es una relación binaria de un conjunto $A = \{a_1, \dots, a_m\}$ a $B = \{b_1, \dots, b_n\}$, la matriz de la relación $M_R = (m_{ij})$ se define como:
\[
m_{ij} = \begin{cases} 
1 & \text{si } (a_i, b_j) \in R \\ 
0 & \text{si } (a_i, b_j) \notin R 
\end{cases}
\]
Por consiguiente, la presencia de $M_{ij} = 1$ confirma formalmente que el par $(a_i, b_j)$ está relacionado en $R$.
</details>

<details class="solution">
<summary>6. Respuesta correcta: B — Matriz de una relación reflexiva</summary>

Una relación $R$ sobre un conjunto $A$ de $n$ elementos es **reflexiva** si $\forall a \in A, (a, a) \in R$.

En términos de su matriz booleana cuadrada $M_R$ ($n \times n$):
- Toda la **diagonal principal** debe estar formada exclusivamente por unos: $M_{ii} = 1$ para todo $i = 1, \dots, n$.
- Los elementos fuera de la diagonal principal pueden ser tanto $0$ como $1$.
</details>

<details class="solution">
<summary>7. Respuesta correcta: B — Cierre transitivo de una relación</summary>

El **cierre transitivo** de una relación $R$, denotado $R^*$, es la relación transitiva más pequeña que contiene a $R$:
- Conserva todos los pares originales de $R$.
- Añade el menor número posible de pares adicionales necesarios para satisfacer que si $(a, b) \in R^*$ y $(b, c) \in R^*$, entonces $(a, c) \in R^*$.
- En matrices booleanas equivale a $M_{R^*} = M_R \lor M_R^{[2]} \lor M_R^{[3]} \lor \dots \lor M_R^{[n]}$ (calculable mediante el Algoritmo de Warshall).
</details>

<details class="solution">
<summary>8. Respuesta correcta: A — Propiedades de las relaciones de equivalencia</summary>

Por definición, una relación binaria $R$ sobre un conjunto $A$ es una **relación de equivalencia** si y solo si cumple tres propiedades simultáneamente:
1. **Reflexiva:** $\forall a \in A, (a, a) \in R$.
2. **Simétrica:** $\forall a, b \in A, (a, b) \in R \implies (b, a) \in R$.
3. **Transitiva:** $\forall a, b, c \in A, (a, b) \in R \land (b, c) \in R \implies (a, c) \in R$.
</details>

<details class="solution">
<summary>9. Respuesta correcta: B — Cierre reflexivo</summary>

El **cierre reflexivo** de una relación $R$ sobre un conjunto $A$, denotado $r(R)$, es la menor relación reflexiva que contiene a $R$.

Se construye uniendo $R$ con la relación de identidad $\Delta_A = \{(a, a) \mid a \in A\}$:
\[
r(R) = R \cup \Delta_A
\]
Algebraicamente añade a $R$ los pares bucle $(a, a)$ que faltaran.
</details>

<details class="solution">
<summary>10. Respuesta correcta: A — Composición de relaciones</summary>

Dadas las relaciones $R \subseteq A \times B$ y $S \subseteq B \times C$, la **composición de relaciones** $S \circ R$ (o $R \circ S$ según notación) es la relación de $A$ a $C$ definida como:
\[
(a, c) \in S \circ R \iff \exists b \in B \text{ tal que } (a, b) \in R \land (b, c) \in S
\]
La matriz booleana de la composición se obtiene directamente mediante el producto booleano de sus matrices: $M_{S \circ R} = M_R \odot M_S$.
</details>

<details class="solution">
<summary>11. Respuesta correcta: C — Definición de Relación Reflexiva</summary>

Una relación $R$ en un conjunto $A$ es **reflexiva** si cada elemento está emparentado o relacionado consigo mismo:
\[
\forall a \in A, \quad (a, a) \in R
\]
*Ejemplos:* La relación $\le$ en los números reales o la relación de igualdad $=$.
</details>

<details class="solution">
<summary>12. Respuesta correcta: A — Definición de Relación Simétrica</summary>

Una relación $R$ en un conjunto $A$ es **simétrica** si la relación se verifica de forma bidireccional para todos los elementos:
\[
\forall a, b \in A, \quad (a, b) \in R \implies (b, a) \in R
\]
En su matriz booleana asociada, la matriz es simétrica respecto a su diagonal principal ($M_R = M_R^T$).
</details>

<details class="solution">
<summary>13. Respuesta correcta: B — Definición de Relación Antisimétrica</summary>

Una relación $R$ en un conjunto $A$ es **antisimétrica** si no existen pares distintos emparentados en ambas direcciones:
\[
\forall a, b \in A, \quad ((a, b) \in R \land (b, a) \in R) \implies a = b
\]
Equivalentemente: Si $a \neq b$ y $(a, b) \in R$, entonces $(b, a) \notin R$. 

*Nota:* No prohíbe los pares $(a, a)$ de la diagonal.
</details>

<details class="solution">
<summary>14. Respuesta correcta: B — Definición de Relación Transitiva</summary>

Una relación $R$ en un conjunto $A$ es **transitiva** si el encadenamiento de dos relaciones intermedias impone la relación directa:
\[
\forall a, b, c \in A, \quad ((a, b) \in R \land (b, c) \in R) \implies (a, c) \in R
\]
*Ejemplos:* Las relaciones de orden $<, \le$ o la relación de inclusión entre conjuntos $\subseteq$.
</details>

<details class="solution">
<summary>15. Respuesta correcta: D — Propiedades no requeridas para Equivalencia</summary>

Para ser una **relación de equivalencia** se exige obligatoriamente:
- Reflexividad
- Simetría
- Transitividad

La **antisimetría** es una propiedad utilizada en las **relaciones de orden** (parcial o total), pero no en las relaciones de equivalencia (salvo en el caso trivial de la igualdad estricta, simetría y antisimetría son mutuamente excluyentes para elementos distintos).
</details>

## Chuleta final: lo imprescindible para aprobar

### 1. Conceptos básicos de relaciones

- **Producto Cartesiano ($A \times B$):** $\{(a, b) \mid a \in A, b \in B\}$.
- **Relación ($R$):** Cualquier subconjunto de $A \times B$.
- **Dominio ($\text{Dom}(R)$):** Conjunto de primeras componentes $\{a \mid (a, b) \in R\}$.
- **Imagen ($\text{Im}(R)$):** Conjunto de segundas componentes $\{b \mid (a, b) \in R\}$.

### 2. Matrices booleanas

- Usan entradas en $\{0, 1\}$.
- **Operaciones:** $\lor$ (OR, disyunción) y $\land$ (AND, conjunción).
- **Producto Booleano ($A \odot B$):** Multiplicación matricial sustituyendo $+$ por $\lor$ y $\cdot$ por $\land$.
- **Matriz de la Composición:** $M_{S \circ R} = M_R \odot M_S$.

### 3. Propiedades fundamentales de relaciones sobre A

| Propiedad | Definición Formal | En la Matriz Booleana $M_R$ |
|---|---|---|
| **Reflexiva** | $\forall a, (a, a) \in R$ | Diagonal principal llena de 1s ($M_{ii} = 1$) |
| **Irreflexiva** | $\forall a, (a, a) \notin R$ | Diagonal principal llena de 0s ($M_{ii} = 0$) |
| **Simétrica** | $(a, b) \in R \implies (b, a) \in R$ | Matriz simétrica ($M_R = M_R^T$) |
| **Antisimétrica** | $(a, b) \in R \land (b, a) \in R \implies a = b$ | Si $i \neq j$ y $M_{ij} = 1 \implies M_{ji} = 0$ |
| **Transitiva** | $(a, b) \in R \land (b, c) \in R \implies (a, c) \in R$ | $M_R \odot M_R \le M_R$ |

### 4. Clasificación de Relaciones y Cierres

- **Relación de Equivalencia:** Reflexiva + Simétrica + Transitiva.
- **Relación de Orden Parcial:** Reflexiva + Antisimétrica + Transitiva.
- **Cierre Reflexivo:** $r(R) = R \cup \{(a, a) \mid a \in A\}$.
- **Cierre Simétrico:** $s(R) = R \cup \{(b, a) \mid (a, b) \in R\}$.
- **Cierre Transitivo:** $t(R) = R^* = \bigcup_{k=1}^n R^k$ (Algoritmo de Warshall).

document.addEventListener("DOMContentLoaded", function () {
  const form = document.getElementById("quiz-form");
  if (!form || form.dataset.initialized === "true") return;
  form.dataset.initialized = "true";

  const questions = Array.from(document.querySelectorAll("#quiz-form .quiz-question"));
  const count = document.getElementById("quiz-count");
  const progressText = document.getElementById("quiz-progress-text");
  const result = document.getElementById("quiz-result");
  const scoreText = document.getElementById("quiz-score");
  const message = document.getElementById("quiz-message");
  const summary = document.getElementById("quiz-summary");
  const reset = document.getElementById("quiz-reset");

  function updateProgress() {
    const answered = questions.filter(q => {
      const input = q.querySelector("input");
      return form.querySelector('input[name="' + input.name + '"]:checked');
    }).length;
    count.textContent = answered + " de " + questions.length + " respondidas";
    progressText.textContent = answered === questions.length
      ? "¡Ya has respondido todas!"
      : "Te faltan " + (questions.length - answered) + " por responder.";
  }

  form.addEventListener("change", updateProgress);

  form.addEventListener("submit", function (event) {
    event.preventDefault();
    let correct = 0;
    let unanswered = 0;

    questions.forEach(function (question, index) {
      const number = index + 1;
      const selected = form.querySelector('input[name="q' + number + '"]:checked');
      const answer = question.dataset.answer;
      const shortExp = question.dataset.shortExp || "";
      const statusEl = question.querySelector(".feedback-status");
      const expEl = question.querySelector(".feedback-exp");
      const labels = question.querySelectorAll("label");

      question.classList.remove("is-correct", "is-wrong");
      labels.forEach(label => { label.style.fontWeight = "normal"; });

      if (!selected) {
        unanswered++;
        question.classList.add("is-wrong");
        statusEl.textContent = "✗ Sin responder. Respuesta correcta: " + answer.toUpperCase();
      } else if (selected.value === answer) {
        correct++;
        question.classList.add("is-correct");
        statusEl.textContent = "✓ ¡Correcto!";
      } else {
        question.classList.add("is-wrong");
        statusEl.textContent = "✗ Incorrecto. Respuesta correcta: " + answer.toUpperCase();
      }

      expEl.textContent = shortExp;

      const correctLabel = Array.from(labels).find(label =>
        label.querySelector("input").value === answer
      );
      if (correctLabel) correctLabel.style.fontWeight = "700";
    });

    const percent = Math.round(correct / questions.length * 100);
    scoreText.textContent = correct + " de " + questions.length + " correctas (" + percent + "%).";
    message.textContent = percent >= 90 ? "¡Excelente! Dominas muy bien el tema." :
      percent >= 70 ? "¡Buen trabajo! Repasa los fallos para afianzar lo aprendido." :
      percent >= 50 ? "Vas por buen camino. Lee las explicaciones cortas y detalladas para afianzar." :
      "Te conviene repasar las explicaciones detalladas con calma y repetir el test.";
    summary.textContent = unanswered
      ? "Has dejado " + unanswered + " pregunta(s) sin responder."
      : "Has respondido todas las preguntas.";

    result.hidden = false;
    result.scrollIntoView({ behavior: "smooth", block: "nearest" });

    if (window.MathJax && MathJax.typesetPromise) {
      MathJax.typesetPromise();
    }
  });

  reset.addEventListener("click", function () {
    form.reset();
    questions.forEach(function (question) {
      question.classList.remove("is-correct", "is-wrong");
      question.querySelectorAll("label").forEach(label => {
        label.style.fontWeight = "normal";
      });
      question.querySelector(".feedback-status").textContent = "";
      question.querySelector(".feedback-exp").textContent = "";
    });
    result.hidden = true;
    updateProgress();
    form.scrollIntoView({ behavior: "smooth", block: "start" });
  });

  updateProgress();
});
</script>
